Connect to GitHub

To publish posts directly to your live site, we need a GitHub Personal Access Token. This is a one-time setup.

🔒 Your token is stored only in this browser and never sent anywhere except GitHub's API.

How to get your token:

  1. Go to github.com/settings/tokens/new
  2. Name it "Mindset Blog Admin"
  3. Set expiration to No expiration (or your preference)
  4. Check the repo checkbox (full control of repositories)
  5. Click "Generate token" and copy it
