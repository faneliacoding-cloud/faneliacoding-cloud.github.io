📖 How the Blog Works

      
The blog uses a simple file-based system. Each post is an HTML file inside a folder. The blog listing page reads posts.json to know which posts exist.

      
To add a new post:

🎨 Content Formatting Guide

      
Use these HTML tags in the content area:

      
    
        
  • <p>...</p> — Paragraph
    • 
        
  • <h2>...</h2> — Section heading
    • 
        
  • <h3>...</h3> — Sub-heading
    • 
        
  • <strong>...</strong> — Bold
    • 
        
  • <em>...</em> — Italic
    • 
        
  • <ul><li>...</li></ul> — Bullet list
    • 
        
  • <ol><li>...</li></ol> — Numbered list
    • 
        
  • <blockquote>...</blockquote> — Quote
    • 
        
  • <div class='pull-quote'>...</div> — Gold-bordered pull quote
    • 
      

    


    

      
🖼 Adding Images

      
Upload images to the assets/ folder on your server first, then reference them as ../../assets/filename.png in the image path field.

    


    

      
💡 Writing Tips

      
    
        
  • Write in a warm, professional tone
    • 
        
  • Aim for 800-1200 words
    • 
        
  • Include a pull quote every 3-4 paragraphs
    • 
        
  • Use specific, actionable advice
    • 
        
  • End with a hopeful, inviting message
